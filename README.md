# Cure Dolly Drills

Fast, pattern-focused Japanese verb drills based on Cure Dolly's conjugation and self-move / other-move rules.

## Development

```sh
pnpm install
pnpm dev
```

## Checks

```sh
pnpm lint
pnpm check
pnpm build
```

## Deployment

Pushes to `main` build and deploy the static Astro site with GitHub Pages.

Site: https://louismollick.github.io/cure-dolly-drills/
